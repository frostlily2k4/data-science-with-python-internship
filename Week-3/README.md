# Week 3 — Python & Data Wrangling

## Project Overview

This project was completed as part of my Data Science with Python Internship.

The project focuses on cleaning, transforming, and visualizing a workout dataset using Python.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed

- Loaded the dataset using Pandas
- Inspected the dataset structure
- Checked rows and columns
- Identified missing values
- Handled missing values
- Filtered rows using conditions
- Created a new `Calories_Per_Minute` column
- Created a Calories vs Duration line chart
- Created a Pulse vs Calories scatter plot
- Created a Calories distribution chart using Seaborn
- Exported the cleaned dataset as CSV

## Dataset

The dataset contains workout information including:

- Duration
- Date
- Pulse
- Maxpulse
- Calories

## Data Cleaning

Missing values were identified and handled appropriately.

The final cleaned dataset contains no missing values.

The cleaned dataset was exported as:
